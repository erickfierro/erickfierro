## 👨‍💻 About Me

Software Engineer with **4+ years of experience** designing, developing, and maintaining mission-critical core systems for banking and insurance. Specialized in **COBOL (Batch & Online)** running in enterprise **Unix/Linux** environments, orchestrating mass data batch workflows using **Shell scripting (.sh)** and **BMC Control-M**, integrated with relational databases (**Oracle**, **DB2**) and flat/sequential file processing.

Possess solid foundational experience in traditional **IBM Mainframe (z/OS, CICS, JCL, VSAM)** architectures, and actively expanding modern backend capabilities with **Java** and **Spring Boot**.

- 💼 **Currently:** Software Engineer at **Nuek**, developing core applications on Unix/Linux and automating massive batch executions.
- 🏦 **Background:** Developed and maintained critical batch and online services at **Banco de Bogotá** and **NTT DATA**.
- 🎓 **Education:** Pursuing Software Engineering at **Corporación Universitaria Minuto de Dios**; graduate in Information Systems Analysis & Development (**SENA**).
- 🧠 **Focus areas:** Batch automation, mission-critical performance tuning, high-volume data consistency, and enterprise modern backend integration.
- 💬 **Ask me about:** COBOL on Linux, Shell automation (`.sh`), Control-M scheduling, Oracle/DB2 integration, and Mainframe fundamentals.
